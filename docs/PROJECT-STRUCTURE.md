# Spanish-A1 · estructura inicial

- `app/`: rutas App Router; páginas de inicio, curso, unidades, progreso, quiz y examen futuro.
- `components/`: navegación, mapa, proveedores y resumen de progreso.
- `content/course.ts`: temario y contenido pedagógico implementado para las Unidades 0 y 1; las unidades futuras solo tienen metadatos.
- `lib/progress-context.tsx`: estado de avance persistido en localStorage.
- `public/audio`, `public/images`, `public/icons`: recursos multimedia futuros.
- `tests/`: espacio reservado para pruebas automatizadas.
- `docs/`: documentación técnica.
